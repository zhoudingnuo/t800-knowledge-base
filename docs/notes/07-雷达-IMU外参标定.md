# 07 - 雷达-IMU 外参标定（T800 Odin2 / Go2 Mid-360）

> 2026-10-05/06 实机标定。两台机器都是"激光雷达+IMU 一体模块"（T800 头部 Odin2、
> Go2 背部 Livox Mid-360），但**模块内部雷达与 IMU 的轴向并不是严格对齐的**；
> point-lio 会把世界系 z 轴对齐到初始化瞬间 IMU 测到的重力方向，于是这个
> LiDAR↔IMU 旋转误差会**原样变成整张地图的整体倾斜**（地面/天花板一起斜）。

## 1. 现象与判据

| 现象 | 含义 |
|---|---|
| 地图地面与天花板**法向平行**（夹角 <0.3°）但都偏离 z 轴 | 整图整体倾斜 → 外参/初始化问题 |
| 地面与天花板**法向不平行**（差一个大角度） | 地面本身是坡（建筑问题），不是外参 |

- 初始化是否干净要看**建图起始的静止段**：前 100 个 IMU 样本（0.25s）的平均重力方向
  与静止段平均只差 0.02° 时，世界 z 是准的（T800 实测 0.018°）。
- 参考真值：T800 用 Odin2 **设备自带里程计**（`odometry_lf`，出厂标定融合）确认
  30.8m 行走高度只变 0.142m → 地面是平的，倾斜全部归外参。

## 4. 标定方法（经验雅可比迭代）

不用设备出厂值（设备不发布 LiDAR-IMU 外参），用数据自己标：

1. **录一袋数据**：起始静止 3~5 秒（初始化干净），行走**多转几个弯**（旋转量决定外参可观测性）；
2. **离线建图**：重放 bag → point_lio 出 `PCD/scans.pcd`；
3. **量倾斜**：对地图取"最低 40% 点"RANSAC 拟合地面平面 → 法向 n；倾角向量 `t = n[:2]`；
4. **测雅可比**：外参加 1° 的 x/y 已知扰动，各重建一次图，得响应矩阵
   `J = [(t_x-t_0)/1°, (t_y-t_0)/1°]`（2×2，自动吃掉所有坐标系约定）；
5. **解修正**：`δ = J⁻¹·(-t)`，`R_new = R·Exp(δ)`（右乘 = LiDAR 系内旋转）；
6. **迭代验证**：重建图量倾斜，直到 <0.3°（一般 2~3 轮收敛，每轮残差约减半）。

脚本（都在机器上，可直接复用）：

| 机器 | 脚本 |
|---|---|
| T800（.162） | `~/t800_bag/jac_one.sh`（单次静止段建图）+ `/tmp/jac_drive.py`（雅可比解算驱动） |
| Go2 | `~/go2_bag/calib_extr.py`（第一轮：测 J + 解算 + 验证）+ `~/go2_bag/calib_round2.py`（读当前 R 继续迭代） |
| 通用 | `semmap/traj_csv2jsonl.py`（`rostopic echo -p` 轨迹 → odom jsonl） |

## 5. 精度上限与注意事项

- **噪声底 = 地面本身的起伏**：同一张图按 10m 分块，地面倾角在 1.06°~1.32° 之间变化
  （Go2 那袋）→ 用"地面当基准"最多到 ~0.3°；T800 那 40m 是整块平层（残差 1.3cm），
  所以能标到 0.11°。
- **别在同一袋上无限迭代**：会把这一袋的局部地面起伏"学进外参"，换场地反而变差。
  想更准就录**更长、转弯更多**的数据重标。
- **平移不可观**：LiDAR↔IMU 平移只有快速旋转时才起作用（杆臂效应，二阶量），
  保持出厂/零值即可；**偏航不可观**（被地图初始朝向吸收），标出来的偏航分量无意义。
- **重新安装雷达后必须重标**（哪怕只动了几度）。
- 地图"整体倾斜"和"局部精度"是两回事：倾斜 3° 的图，局部平面残差仍可只有 1cm——
  倾斜只影响地图相对重力/水平面的姿态。
