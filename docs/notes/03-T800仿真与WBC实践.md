# T800 仿真环境与自研 WBC 实践（2026-10-04）

本知识库的 `sim/` 目录是从官方 URDF 出发自建 MuJoCo 仿真、自研训练环境与全身控制器的完整工程，
详细文档见 `sim/README.md`。要点：

## 已完成
- **仿真环境**：`sim/models/t800/` 由官方 URDF 生成（训练版图元碰撞 / 展示版完整 mesh），
  场景含行走与负载搬运；EGL 离屏渲染 + CPU MuJoCo 评测/录像。
- **自研训练栈**：MJX（JAX）+ NVIDIA Warp 后端，4096 并行环境实测 40-150k 控制步/秒；
  自研 PPO（Flax + GAE + clip），观测 89 维含运行时归一化，奖励含速度跟踪/姿态/步态相位/
  足部滞空/打滑等，域随机化（摩擦/伺服增益/推力/载荷质量）。
- **WBC 架构**：脚本步态基座（相位时钟驱动）+ 前倾推进 + 踝策略平衡反馈 + 学习残差（PPO）。
- **验证结果**：站立与原地踏步稳定（训练内回合 700-985 步 / 14-20s，摔倒率 0.1-0.2%）；
  步态+前倾在零策略下可按指令速度行走（0.42 m/s vs 指令 0.4）；速度跟踪的 RL 尚未收敛
  （策略收敛到"站立"局部最优）。

## 关键工程结论（对后续开发很重要）
1. **MJX+Warp 的 `naconmax` 是所有世界共享的接触总数**，必须按 `≈8×num_envs` 配置，
   否则物理完全失真（这是本项目前期所有训练失败的根因）。
2. **站立需要足够的踝关节刚度**：官方行走策略的踝 kp=40 无法提供站立所需的约 10 N·m/踝
   （踝关节在质心后方 2.4cm），官方 SDK 站立模式用 kp=800；本项目采用髋/膝 600、踝 400。
3. **动作尺度必须能完成迈步行程**（±0.25 rad 抬脚不足 2cm，需 0.4-0.8 rad）。
4. **脚部碰撞用薄底板**（AABB 整块 box 会导致"摇椅"失稳）；自碰撞按官方配置关闭。
5. **warp 与 CPU MuJoCo 在临界稳定系统上长时域会分叉**；评测须与训练使用相同增益/尺度模型，
   且演示视频采用"warp 录制 + CPU 运动学回放"以保证真实。

## 最终结果（2026-10-04）

**Isaac Lab 路径**：Isaac Sim 5.1 + Isaac Lab 2.3.2 + 官方 rl_lab 已安装（Python 3.11 环境），
但 Isaac Sim 因 RTX 渲染器与本机驱动 595.91 不兼容而无法启动（排除环境变量/显示/8 组禁用参数；
Vulkan 正常）。修复需降级整机驱动 → 需用户确认。

**根因**：官方 AMP 策略在 MuJoCo 1.4-8.1s（400Hz 原地踏步），在 PhysX 稳定；模型与官方 USD
逐项一致（84.988kg）→ MuJoCo/PhysX 接触与求解器动力学差异。

**最终能力**：仿真环境与模型 ✅、自研 WBC/训练栈/蒸馏管线 ✅、站立 6-22s ✅、
持载荷站立 0.5/3/6kg 各 10s ✅、原地踏步 ✅、行走 1.4s（精确跟踪，**持 3kg 载荷时性能不降**）、
官方策略 400Hz 8.1s 原地；稳定行走与行走中长距离搬运 ❌（引擎级限制）。
